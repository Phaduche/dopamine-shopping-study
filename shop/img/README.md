# 상품 사진

이 폴더에 `상품id.확장자` 이름으로 사진을 넣으면 데모 쇼핑몰이 그 상품의 그림 대신 사진을 보여 줍니다.

- 예: `p01.jpg`, `p02.png`, `p15.webp` (jpg / jpeg / png / webp)
- 상품 id와 이름은 `shop/products.js`에서 확인·수정할 수 있습니다.
- 정사각형(예: 800×800) 사진이 쿠팡 목록처럼 가장 자연스럽게 보입니다.
- 사진이 없는 상품은 기존 SVG 그림이 그대로 나옵니다.
- 서버를 다시 켤 필요 없이 페이지를 새로고침하면 반영됩니다.
