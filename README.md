# 쇼핑 경험 연구용 웹앱 (로컬 실행)

KSEF 연구용 모의 쇼핑 실험 도구입니다. 참가자가 사전 설문(T0)에 답하면 조건이 배정되고,
조건에 따라 데모 쇼핑몰 또는 실제 쿠팡으로 이동합니다. 설문 응답과 데모 쇼핑몰 안의 행동 로그는
로컬 SQLite DB에 저장되고, 연구자 콘솔에서 CSV로 내려받을 수 있습니다.

## 실행

파이썬 3만 있으면 됩니다 (추가 설치 없음).

```bash
python3 server.py
```

- 참가자 시작 화면: http://localhost:8000
- 연구자 콘솔: http://localhost:8000/admin.html

기본으로는 이 컴퓨터에서만 접속할 수 있습니다. 같은 와이파이의 폰·태블릿에서도 열려면 `--lan`을 붙입니다.

```bash
python3 server.py --lan
```

실행하면 `http://192.168.x.x:8000` 같은 주소가 출력되고, 같은 와이파이에 있는 기기에서 그 주소로 들어가면 됩니다.
`--lan`일 때는 같은 네트워크의 누구나 연구자 콘솔(`/admin.html`)에도 들어올 수 있으니 실험용 와이파이에서만 쓰세요.
데모 쇼핑몰은 쿠팡과 같은 이름·화면을 쓰므로 **로컬 실험 전용**이며, 웹에 공개 배포하지 않습니다 (GitHub Pages 꺼 둠).

## 흐름

1. 안내·동의 → 사전 설문 4단계 (기본 정보, 지금 기분, 구매욕구, 쇼핑 습관)
2. 서버가 무작위 연구 ID(예: `P3A9F1C`)를 만들고 조건을 배정
3. 조건 0 → 데모 쇼핑몰 `/shop/`, 조건 1 → https://www.coupang.com/

## 조건 배정 (연구자 콘솔)

| 방식 | 동작 |
| --- | --- |
| 고정 | 콘솔에서 고른 조건(0 또는 1)으로 이후 참가자를 모두 배정 |
| 무작위 | 참가자마다 0/1을 컴퓨터 난수로 배정 (단순 무작위, 층화 없음) |

설정은 저장한 다음 참가자부터 적용됩니다.

## 데이터

- 원본: `data/study.db` (SQLite) — `.gitignore`에 포함되어 git에 올라가지 않습니다.
- `participants.csv`: 연구 ID, 시작 시각, 조건, 배정 방식, 설문 문항별 응답 (문항 id가 열 이름)
- `events.csv`: 행동 로그 — `assigned`, `app_open`, `screen`(이전 화면 체류시간), `product_view`, `search`,
  `cart_add`, `cart_remove`, `cart_qty`, `buy_now`, `checkout_view`, `order`, `track_view`, `leave`, `return`
- 조건 1(실제 쿠팡)로 이동한 뒤의 행동은 기록할 수 없습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `server.py` | 로컬 서버 + SQLite + CSV 내보내기 |
| `index.html` | 동의·사전 설문 화면 |
| `survey-config.js` | 설문 문항 정의 — 문항은 이 파일만 고치면 됩니다 |
| `admin.html` | 연구자 콘솔 |
| `shop/` | 데모 쇼핑몰 (홈, 검색, 상품상세, 장바구니, 주문결제, 주문완료, 주문·배송조회) |

데모 쇼핑몰 상품은 64종, 카테고리 10개(패션·뷰티·식품·주방·생활·홈인테리어·가전디지털·스포츠·문구·반려동물)입니다.
이 중 p01~p20이 연구계획서 §6.3 기준 실험 상품(문구·소형 생활용품)이고, 나머지는 쇼핑몰처럼 보이게 하는 채움용입니다. 브랜드는 모두 가상입니다.
상품 사진 60장은 자유 이용 라이선스(CC0·퍼블릭 도메인·CC BY·CC BY-SA) 사진이며 출처는 `shop/img/CREDITS.md`에 있습니다.
사진을 바꾸려면 `shop/img/`의 파일을 같은 이름으로 교체하면 됩니다 (자세한 건 `shop/img/README.md`).
배송 단계는 주문 후 경과 시간으로 정해집니다: 결제완료 → 상품준비중(6시간) → 배송중(24시간) → 배송완료(72시간).
