# 클론팡 · 쿠팡 스타일 쇼핑 페이지 (로컬 실습용)

쿠팡 UI를 참고해 만든 단일 HTML 쇼핑 페이지입니다. 실제 쿠팡과 관련이 없으며, 상품·가격은 모두 가상입니다.

## 실행

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 열면 됩니다. (`index.html`을 직접 열어도 동작합니다.)

## 기능

- 카테고리 메뉴, 검색(카테고리 선택 포함), 자동 슬라이드 배너
- 오늘의 골드박스 (자정까지 카운트다운)
- 상품 카드: 할인율·정가·할인가, 로켓배송 도착 보장일, 별점
- 장바구니: 담기, 수량 조절, 합계, 가상 주문 (localStorage에 저장)
