# 담아마켓 · 연구용 모의 쇼핑 앱 (KSEF)

실물 없는 디지털 쇼핑 의례가 정서와 구매욕구에 미치는 영향을 검증하기 위한 **연구용 모의 쇼핑 애플리케이션**입니다. 연구계획서 v6의 **1단계(작동원리 연구) R / F / C 3조건**을 구현합니다.

> ⚠️ **이 앱은 실제 쇼핑몰이 아닙니다.** 실제 결제·판매·배송·광고가 없으며, 상품·브랜드·가격은 모두 연구용 가상 정보입니다. 실제 기업 브랜드나 상표를 모방하지 않습니다(v6 §7.2).

---

## 무엇을 하는 앱인가

쿠팡과 같은 온라인 쇼핑의 **UI 패턴과 쇼핑 의례 경험**(상품 탐색 → 선택 → 장바구니 → 주문 → 배송조회(날짜 실시간 변경) → 배송완료)을 가상 브랜드로 동일하게 재현하고, 실험조건에 따라 경험을 분기하며, 자연스러운 **행동로그**를 자동 수집합니다.

### 실험 조건 (URL 파라미터로 배정)

| 조건 | 경험 | 분리하려는 요소 |
| :-- | :-- | :-- |
| **R** 실제 보상 | 탐색·선택 → 장바구니 → 주문 → 배송조회 → 72h 후 **실물 수령** 안내 | 실제 상품 기대·획득 총효과 |
| **F** 모의 배송 | R과 동일 UI·상품·시간표, **배송 없음 명시** → 72h 후 **가상 배송완료** | 실물 없는 주문·대기·조회 의례 |
| **C** 단순 탐색 | 동일 상품을 탐색·평가 후 **가장 선호 상품 선택** (주문·배송 화면 없음) | 상품 노출·선택만 통제한 대조 |

접속 URL 예시:

```
https://<배포주소>/?cond=F&pid=P017          # F조건, 참가자 P017
https://<배포주소>/?cond=R&pid=P002&sim=1440  # R조건 + 시간가속(데모)
https://<배포주소>/?cond=C&pid=P040          # C조건
```

- `cond` = `R` | `F` | `C` (미지정 시 기본 `F`)
- `pid` = 무작위 연구ID (개인정보 아님)
- `sim` = 시간가속 배율(데모용). 예) `1440`이면 72시간이 약 3분으로 압축. 미지정 시 실시간.

## 핵심 기능

- **쿠팡형 UI**: 검색바·카테고리·상품 그리드·번개배송 배지·상품상세·장바구니·주문·배송조회
- **결제 비활성화**: 주문은 접수되지만 실제 카드·계좌·결제 정보를 입력받지 않음
- **배송조회 날짜 실시간 변경**: 72시간 타임라인(주문완료→준비중→집화→배송중→배송완료), 예상 도착일·현재시각이 실시간 갱신
- **조건 분기**: C조건은 장바구니/주문/배송 화면 자체가 노출되지 않음
- **측정시점 설문 T0~T7**: 부정/긍정정서, 상태 구매욕구(VAS), 통제감·기대감·소유감·종결감·만족도, 조작점검 등 (v6 §8·§16)
- **행동로그 자동 수집**(v6 §7.3·§15): 앱 실행, 화면별 체류시간, 상품조회·비교, 장바구니 추가/삭제, **배송조회 횟수·시각**, 설문 응답시간, 선호선택/목표변경, 추가탐색
- **연구 관리자 콘솔**(`/admin`): 조건 배정, 참가자 URL 생성, 로그 요약 통계, 측정시점 진행상태, **JSON/CSV 내보내기**, 초기화

> 📌 설계 철학(v6 §16·§25): 이 앱의 경쟁력은 화려함이 아니라 **실험조건을 정확히 통제하고 자연스러운 행동자료를 수집**하는 데 있습니다.

### 수집하지 않는 정보 (v6 §15)
결제·계좌·쇼핑몰 로그인 정보, 연락처·사진·위치정보, 앱 밖 활동, IP·광고식별자. 모든 로그는 무작위 `pid`로만 연결되며 **기기 로컬(localStorage)에만** 저장되고 서버로 전송되지 않습니다.

## 로컬 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

- Node.js 18+ 권장
- 스택: React 18 + Vite 5 + React Router 6 (외부 런타임 의존성 최소화, 상품 이미지는 코드 생성 썸네일로 외부 이미지·저작권 이슈 없음)

## Vercel 배포

1. 이 저장소를 GitHub에 올립니다(이미 등록되어 있다면 생략).
2. [vercel.com](https://vercel.com) 로그인 → **Add New → Project** → 이 GitHub 저장소 **Import**.
3. 프레임워크가 **Vite**로 자동 감지됩니다. 추가 설정 없이 **Deploy**.
   - Build Command: `npm run build` · Output: `dist` (`vercel.json`에 설정되어 있음)
4. 배포 완료 후 발급된 URL 뒤에 조건/참가자 파라미터를 붙여 배포합니다.

> Netlify로 배포할 경우: Build `npm run build`, Publish `dist`, SPA 리다이렉트(`/* → /index.html`)만 추가하면 됩니다.

## 윤리·규정 (중요)

- 본 연구는 **미성년자 대상 사람 대상 연구**입니다. **IRB/SRC 사전승인 전에는 실제 참가자 자료를 수집하지 않습니다**(v6 §19). 승인 전 사용은 연구팀 내부 기술 디버깅으로 한정합니다.
- 실제 쇼핑몰 브랜드·상표·상품사진을 사용하지 않습니다. 가상 브랜드 "담아마켓"과 코드 생성 썸네일을 사용합니다.
- F조건은 실제 배송이 없음을 반복 고지하여 기만을 최소화합니다(v6 §19).
